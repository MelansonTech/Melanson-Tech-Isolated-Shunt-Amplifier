# Archive

Files kept for history that are **not part of either CircuitStudio project**. Neither
`MelansonTech Isolated Current Sense.PrjPcb` nor `...Rev 2.PrjPcb` references anything in here,
so nothing in this folder is opened when you build the design. Do not add files here by hand —
move them with `git mv` so the history follows.

| File | Why it's here |
|---|---|
| `MelansonTech Isolated Shunt Amplifier Rev 2.CSPcbDoc` | **Misleading name.** Despite "Rev 2", this is the *older* layout (Feb 2026). The Rev 2 project actually builds `MelansonTech Isolated Shunt Amplifier.CSPcbDoc` in the repository root. Archived so nobody opens the wrong board. |
| `MelansonTech Isolated Shunt Amplifier.SchDoc` | Superseded amplifier sheet. The live sheets are `...rev 2 alt shunt.SchDoc` (Rev 2) and `...rev 2.SchDoc` (Rev 1). |
| `MelansonTech Boost PSU_IsolatedShuntAmp.SchDoc` | Boost-converter PSU variant, not used by either project. The live PSU sheets are `MelansonTech PSU_IsolatedShuntAmp Rev2.SchDoc` and `...PSU_IsolatedShuntAmp.SchDoc`. |
| `MelansonTech Boost PSU_IsolatedShuntAmp tmp.SchDoc` | Working scratch copy of the above. |
